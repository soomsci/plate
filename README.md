# 경계선

중학교 2학년 학생이 전 세계 지진·화산 분포를 관찰하고 판 경계를 직접 그려 제출하는 45분 수업용 웹앱입니다. 모둠 활동(1~7모둠) 또는 개별 활동(1~25번)으로 진행하며, 교사 대시보드에서 제출한 선을 실시간으로 겹쳐 보고 실제 판 경계와 비교한 뒤 일본·한반도 적용 활동을 진행할 수 있습니다.

## 구성

- 학생: 판 생성·섭입 과정 사전 학습, 직접 찾은 화산·지진 파일 업로드, 화산·지진·함께 비교 챕터, 시간 누적 재생
- 교사: 반별 고정 코드 등록·재사용, 같은 코드로 새 수업 시작, 지진·화산 보조 자료 개별 배포, 교사 지도 레이어 토글, 제출 현황, 모둠 선 중첩, 실제 경계 공개, 동아시아 단계 제어, 수업 종료·재개
- 데이터: USGS 지진·판 경계, Smithsonian GVP 홀로세 화산의 고정 스냅샷
- 지도 엔진: Leaflet과 Natural Earth 110m 해안선을 앱 내부에 포함
- 백엔드: 교사 Google 로그인·학생 익명 인증 + Cloud Firestore
- 배포: Firebase Hosting

Firebase 설정이 비어 있으면 같은 브라우저의 탭 사이에서 시험할 수 있는 `로컬 시연 모드`로 작동합니다.

## 로컬 실행

정적 파일을 HTTP 서버로 열어야 ES 모듈과 데이터 파일이 정상 동작합니다.

```powershell
npm.cmd run serve
```

표시된 주소에서 `/teacher.html`을 열어 반 이름과 고정 수업 코드를 등록한 뒤, 학생 입장 주소를 새 탭에서 엽니다. 실제 사이트에서는 데이터베이스에 저장된 수업 목록을 로그인 없이 바로 불러옵니다. 다음 수업에는 저장된 반을 선택해 같은 코드를 다시 사용할 수 있고, 이전 참여 기록을 비워야 할 때는 `같은 코드로 새 수업 시작`을 누릅니다.

교사 화면의 `저장된 수업 불러오기`는 계정·기기에 관계없이 DB의 수업 목록을 표시합니다. 과거에 목록에서 숨긴 수업도 DB에 남아 있으면 표시합니다. 목록을 선택하면 기존 코드와 진행 단계를 확인할 수 있으며, 비교·공개·종료 단계의 제출 기록을 조회합니다. 조회만으로 소유자나 수업 내용을 바꾸지 않습니다.

수업 생성에는 Google 로그인이 필수가 아닙니다. 다른 기기에서 가져온 수업은 조회 모드로 열리며, 수업 단계 변경·제출 삭제·새 수업 시작은 기존 관리자만 사용할 수 있습니다. 탐구 중인 학생 제출은 기존 관리자에게만 표시됩니다.

다른 컴퓨터에서도 수업을 **제어**하려는 경우에만 `수업 관리 계정 연결 · 선택 사항`을 사용합니다. 원래 수업을 만든 컴퓨터의 같은 브라우저에서 Google 계정을 연결한 뒤 같은 계정으로 로그인하면 관리 권한이 이어집니다. 로컬 시연은 브라우저 내부 저장소를 사용하므로 실제 기기 간 조회는 Firebase 사이트에서 동작합니다.

코드를 처음 만들 때 `진행 방식`에서 모둠 활동 또는 개별 활동을 선택합니다. 개별 활동에서는 학생이 자신의 번호(1~25번)로 접속하며, 교사는 번호별 제출 현황과 근거를 확인합니다. 한 번호는 한 기기에서 사용하고 같은 기기에서 새로고침하면 이어서 참여합니다. 기존 코드는 모둠 활동으로 유지되며, 저장된 코드 재사용·새 수업 시작 시에도 진행 방식은 유지됩니다. 진행 방식을 바꾸려면 새 코드를 만드세요.

## 데이터 스냅샷 만들기

```powershell
node scripts/fetch-data.mjs
```

종료일을 고정하려면 다음처럼 실행합니다.

```powershell
node scripts/fetch-data.mjs 2026-09-02
```

전 세계 지진은 2000년 이후 규모 5.0 이상 자료를 2도 격자별로 시간 층화해 화면용으로 줄입니다. 한반도 상세 레이어는 현재 공개 키 없이 생성 가능한 USGS 규모 2.5 이상 지역 자료입니다. 기상청 또는 KIGAM API 키를 준비하면 검토한 국내 지진 스냅샷으로 교체하세요. 앱의 범례는 공통 자료와 상세 자료의 개수를 직접 비교하지 않도록 안내합니다.

학생이 업로드한 CSV 또는 JSON은 서버에 저장되지 않고 해당 브라우저 지도에만 적용되며, 시간 막대를 재생하면 화산과 지진이 시간순으로 누적 표시됩니다.

새 수업에서는 `학습 완료 · 데이터 탐구 시작` 버튼이 잠겨 있습니다. 교사가 대시보드에서 `데이터 탐구 시작 허용`을 켜야 학생이 지도 단계로 넘어갈 수 있으며, 다시 잠그면 학생은 원리 학습 화면으로 돌아갑니다. 지도 단계에서는 학생이 직접 찾은 화산·지진 파일을 올리고, 업로드한 자료에 해당하는 챕터부터 탐구합니다. 학생이 자료를 구하지 못한 경우에만 교사가 `화산 자료 배포` 또는 `지진 자료 배포`를 켭니다. 그러면 별도 다운로드 없이 해당 교사 제공 좌표가 학생 지도에 즉시 표시됩니다. 학생이 직접 업로드한 자료가 있으면 그 자료가 우선 유지되며, 사용 가능한 두 자료가 모두 갖춰지면 `2-3 함께 비교`가 활성화됩니다.

## Firebase 연결

1. Firebase 프로젝트와 Web App을 만듭니다.
2. Authentication에서 학생용 익명 로그인과 교사용 Google 로그인을 활성화합니다. `firebase.json`의 `auth.providers` 설정으로도 활성화할 수 있습니다.
3. Firestore Database를 생성합니다.
4. Firebase Console의 SDK 설정을 [public/firebase-config.js](public/firebase-config.js)에 입력합니다.
5. `.firebaserc.example`을 `.firebaserc`로 복사하고 프로젝트 ID를 입력합니다.
6. 보안 규칙과 Hosting을 배포합니다.

```powershell
firebase deploy --only auth,firestore:rules,hosting
```

교사는 수업을 만든 인증 UID로 수업 제어 권한을 갖습니다. Google 계정 연결은 선택 사항입니다. 기존 익명 수업의 계정 연결은 해당 수업 소유자의 인증이 유지된 브라우저에서만 가능합니다. 학생은 별도의 회원가입이나 실명 입력 없이 익명 인증을 사용합니다.

## 점검

```powershell
node scripts/check.mjs
node scripts/check-teacher-auth.mjs
```

로컬 서버가 실행 중일 때 Chrome 기반 브라우저 흐름도 점검할 수 있습니다.

```powershell
node scripts/browser-smoke.mjs
```

`PARTICIPATION_MODE=individual`로 같은 브라우저 점검을 실행하면 25번 입장부터 제출·비교·재접속·새 수업 시작까지 개별 모드로 확인합니다. 기본값은 기존 모둠 모드입니다. 두 모드 모두 새 기기의 DB 수업 목록 조회, 기존 소유권 유지, 조회 모드의 제어 차단과 공개 단계의 제출 기록 조회를 검증합니다. Google 계정 연결·기존 계정 병합·실패 시 보존은 `check-teacher-auth.mjs`에서 Firebase SDK 경계를 대체하여 검사하며, 실제 Google 팝업 로그인은 사용자 계정으로 확인해야 합니다. macOS에서는 `CHROME_PATH`에 Chrome 실행 파일 경로를 지정합니다.

Firebase 설정 후에도 로컬 시연 모드를 확인하려면 로컬 주소에 `?backend=local`을 붙입니다. 이 옵션은 `localhost`와 `127.0.0.1`에서만 작동합니다.

수업 운영 및 기능 명세는 [판_경계_추론_수업_계획.md](판_경계_추론_수업_계획.md)를 참고하세요.
